# TG ECET 2027 ECE App — Functional V2

## Included
- Polished Material 3 dashboard
- Bottom navigation: Home / Plan / Practice / Progress
- Complete 180-day plan
- 40 original practice MCQs across 8 subject areas
- Chapter and subject filtering
- Interactive quiz with answer feedback and explanations
- Quiz scoring and percentage result
- Local saved progress using SharedPreferences
- Formula/shortcut starter library

## Run
flutter pub get
flutter run

## Build APK
flutter build apk --release

The MCQs are original practice questions created for this app; they are not presented as official TG ECET questions.
